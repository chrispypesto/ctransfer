# Security policy

## Reporting a vulnerability

Please don't open a public pull request or discussion for a security problem. Report it privately instead, either way:

- On GitHub: the **Security** tab of this repo → **Report a vulnerability**.
- By email: chris@itschrispy.com.

Say what's affected, how to reproduce it, and what an attacker could do with it. Reports about the `ctransfer` client, the `/ctransfer` plugin, the agent that runs on the VM, and the hosted service at `ctransfer.itschrispy.com` are all welcome.

## Supported versions

Only the latest commit on `main` gets fixes.
